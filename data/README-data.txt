The data files in this directory are used in the labs and homeworks. I generally try to rely on datasets from 
libraries, e.g., [PyTorch Geometric datasets](https://pytorch-geometric.readthedocs.io/en/2.5.2/modules/datasets.html). 
However, in some cases it is easier to work with smaller datasets for demonstration purposes. Where used, the 
labs and homeworks use relative paths and assume the following directory structure to load datasets:

YOUR-ML4G-PROJECT-DIRECTORY
-- data (with the same structure as this repository)
-- labs
    ---- lab_01 ...
-- homeworks
    ---- hw_01 ...
